Native desktop platform

Anodrel

A native-first foundation for secure, modular desktop applications: direct operating-system services, explicit permissions, and versioned IPC built directly on platform APIs—without a browser runtime.

View the project

Design principles

Make the important boundaries explicit.

Native by design

Production runtime code uses Anodrel modules, language standard libraries, and direct operating-system APIs.

Explicit trust

Capabilities, protocol versions, and host communication are documented, bounded, and tested at their trust boundaries.

Small modules

Platform services are narrow, testable components—never a framework-sized global dependency.

Current foundation

Windows host, private transport, and controlled native UI.

Anodrel is shared infrastructure, not a single application. Today it includes a direct Win32 host, a versioned protocol, bounded framing, authenticated local IPC, controlled native UI surfaces, and bounded native session menus. Future applications can use the same documented security and platform-service boundaries without embedding a browser engine.
