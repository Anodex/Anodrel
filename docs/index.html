Design principles

Own the important boundaries.

Native by design

Production runtime code uses Anodrel modules, language standard libraries, and direct operating-system APIs.

Explicit trust

Capabilities, protocol versions, and host communication are documented, bounded, and tested at their trust boundaries.

Small modules

Platform services are narrow, testable components—never a framework-sized global dependency.

Current foundation

Windows host, private transport, and controlled content.

Anodrel currently includes a direct Win32 host, protocol and JSON layers, bounded framing, and an authenticated named-pipe adapter limited to the current Windows logon session. Its first controlled application surface verifies a bounded manifest and content digest before direct Win32 text rendering.
